# 流迹 1.1.16

版本 `1.1.16`，`versionCode 24`，包名 `com.liujii.ledger`，最低 Android 8.0。沿用原发布签名，数据库仍为版本3。

## 外观

- 遮罩在45%—100%之间完全遵循滑杆，不再根据图片复杂度暗中增加透明遮罩。
- 流水金额留出16dp右边距，大字体或大金额优先上下排列；备注省略，金额允许换行而不缩成小字。
- 多操作退出弹窗使用居中、至少48dp的按钮；统计等文字采用明暗主题语义颜色。

## 导出与恢复

- CSV 保留 UTF-8 BOM 和数值金额，文本字段增加公式注入防护。
- 完整备份为 ZIP 格式，包格式版本1，内含业务 JSON v3、外观和实际背景图片。继续导入 JSON v1—v3。
- 背景丢失时可重新选择，或明确选择不带图片导出；后者使用渐变背景。
- 恢复先显示版本、时间、笔数、日期范围和背景预览；确认使用同一份已验证数据，不从外部文件重新读取不同内容。
- 文件名白名单、长度及SHA-256校验；单份业务JSON和图片分别不超过64MiB，解压内容合计不超过128MiB。
- 恢复前先保存唯一文件名的完整保护备份，不覆盖旧保护文件；保护文件写入失败不替换账目。
- 数据、外观和提醒恢复分别反馈；外观失败不会谎报账目未改变。中断恢复仅提示检查，不自动覆盖。
- 提供最近保护备份预览入口、最近成功导出时间和可关闭的每7天应用内备份提醒。

备份未经加密，包含私人账目和图片，请勿随意分享。应用锁、解锁状态、草稿与系统权限不迁移；旧JSON没有外观时保留当前外观。

## 开源与自动检查

自有源码采用 MIT，版权署名 `2026 ggbo13`。依赖与 Gradle Wrapper 保留各自许可，私人账目、图片与密钥不上传。

GitHub Actions 固定Action提交SHA，以只读仓库权限运行。构建、两种变体单元测试和Lint与API30／API36模拟器实测分开执行，报告保留7天。不接触正式签名，不自动发布Release，不自动合并PR。

## 验证与安装

本版增加备份、CSV、遮罩和提醒单元测试，以及内存数据库恢复和多尺寸界面测试。实际通过、失败、跳过数量及截图见PR关联的GitHub Actions报告；本机未连接手机或模拟器，不能把本地编译成功视为设备实测通过。正式安装包SHA-256随本机交付文件提供，CI不生成正式签名包。

旧版用户先导出备份，再使用同签名安装包覆盖安装，不要先卸载旧版。旧版应用不能读取新的ZIP格式，需要1.1.16或更高版本；本版仍可读取旧JSON备份。
