# 流迹 1.1.18 · 活页账本

版本号 `1.1.18`，versionCode `26`。本轮将用户已选A+交互预览落到原生Compose界面，并采用A「账页与书签」新图标。

## 界面

- 首页以月份账页呈现本月结余，收入与支出分栏；淡人民币纹、轻纸边、20格预算刻度。大字体时收支改为上下排列。
- 账本管理放在首页上方，预算管理、近期账单与可编辑最近流水继续保留；流水按日期轻分组。
- 快速记账改为主页面顶部加号，避免悬浮按钮遮住流水金额。明细继续全宽、金额右侧保留16dp，日历继续七列。
- 统一账页圆角、分隔线、页眉与主题语义文字色。沿用四套官方主题、自定义图片及45%—100%遮罩。
- 底栏书签220ms滑动，页面按方向28dp位移与260ms淡入淡出；支持外观设置关闭动效并遵循系统动画倍率。
- 记账弹层呈现入账单样式，继续使用Material展开，成功后才显示保存反馈；原有草稿、新建隔离、返回提示和键盘避让保留。
- 新图标使用深薄荷底、纸白账页、人民币符号及金色书签，包含自适应、圆形与Android 13起的单色资源。

## 数据与安装

包名仍为`com.liujii.ledger`，数据库与业务JSON版本3、完整备份包版本1不变。账目ID、分类手动顺序、账本及收支方式关联不变，不预装合成测试账目。

正式包继续使用原签名，可覆盖安装1.1.17。安装前建议导出完整备份；不要卸载旧版。旧安装包、签名及备份均保留。
