# 流迹 1.1.15

版本号 `1.1.15`，`versionCode 23`，包名 `com.liujii.ledger`。最低 Android 8.0，沿用原发布签名。数据库与 JSON 备份仍为版本 3。

## 更新内容

- 记账和周期账单中的分类多行排列，遵循手动顺序，不再按最近使用记录重排；保留有效选中项，必要时回退到首个启用项。
- 分类、账本、收支方式提供默认折叠的已停用列表，可重新启用并追加到末尾；保留历史 ID 和关联。
- 备注聚焦与键盘高度变化时，按输入框实际位置滚动。
- 保存状态与草稿会话由 ViewModel 持有，防止界面重建导致重复提交；成功后即使表单已移除，也会清理相应草稿，迟到回调不会覆盖新表单。
- 启用、停用、保存及预算删除增加处理中和失败提示；在事务内保护最后一个启用账本/收支方式，以及有效周期规则的依赖。
- 统计汇总缓存、分类明细懒加载、图表手势方向判定；横向查看数据，纵向滚动页面。
- 当前日期在前台恢复、跨午夜及系统时间变化时刷新，不改变用户选择的日历日期或编辑日期。
- CSV 保存文件选择前的筛选条件，返回后读取数据库，避免进程重建后的空列表被当作成功导出。
- 备份快照、保护文件写入和数据库替换共用事务；文件异常明确反馈，数据恢复失败与提醒恢复失败分别说明。
- 有效周期账单引用停用项目的备份在恢复前拒绝；超过结束日期的规则不再继续入账。
- 保留自定义背景、七色配色、全宽明细及七列月历，增强颜色勾选对比和主题文字可读性。
