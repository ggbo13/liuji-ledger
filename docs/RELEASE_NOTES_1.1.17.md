# 流迹 1.1.17

版本1.1.17，versionCode 25，包名`com.liujii.ledger`，最低Android 8.0。沿用原签名，Room与业务JSON仍为版本3，完整备份包仍为版本1。

## 界面与官方主题

- 新增清透薄荷、雾海蓝、暖杏、暮山紫四套内置主题，每套都有白天与黑夜配色；主题预览以勾选和“使用中”标记，窄屏和大字体改为单列。
- 点击主题同时应用配套渐变背景，不改变明暗模式和遮罩；原图片仍留在本机，可点击“恢复上次图片”，失效图片不会被当作恢复成功。
- 升级保留原背景与45%—100%遮罩；新安装默认清透薄荷、跟随系统。收入保持绿、支出保持红，分类七色不变。
- 统一字号、圆角、主题表面和导航配色；全宽明细及金额16dp右边距继续保留，预算金额使用更适合大字体的上下标签。

## 动效与流畅性

- 主页面与二级页面增加280ms横向位移及淡入淡出，主题换色250ms，停用分组展开收起220ms。
- 外观页可关闭界面动效，遵循系统动画设置；首次启动直接显示正确配色，应用锁直接遮挡内容。
- 页面状态按独立键保存，退出中的页面不再接收点击或截获返回；二级页滚动位置保留。保存按钮增加轻微按压反馈；金额不使用数字滚动动画，图表游标与左滑删除仍立即响应。
- 主过渡层自身避开底部导航区域，连续点击导航不依赖上一页动画结束；测试直接注入触摸，不只调用语义点击。
- 同一明暗模式内切换主题使用250ms换色；白天与黑夜直接应用目标配色，避免黑白插值期间出现灰字灰底的短暂低对比。
- 日历当日流水改为懒加载，图表路径缓存与游标覆盖层分离；背景继续按屏幕采样和缓存，无实时模糊或持续动态背景。
- 备注避让除焦点和键盘高度外，也跟踪输入框实际高度，覆盖大字体和浮动标签改变字段尺寸的情况。

## 备份兼容与隐私

完整ZIP增加可选主题和动效字段，继续导入旧ZIP及JSON v1—v3。旧外观缺少主题字段时使用薄荷配色并保留原渐变，未知主题ID回退薄荷。备份只包含当前启用的背景，不额外打包未启用的旧图片；应用锁、草稿与权限不迁移。
