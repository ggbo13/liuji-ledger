# 流迹 1.1.19 · 月总账单与年总账单

版本号 `1.1.19`，versionCode `27`。本版在统计页增加完整月账单和年账单查看入口，不改变现有账目、分类、账本、收支方式或备份格式。

## 新增功能

- 统计页新增“月总账单”和“年总账单”入口。
- 月总账单按完整自然月汇总，年总账单按完整自然年汇总。
- 支持查看上一个月／下一个月、上一年／下一年，并可一键回到当前月份或年份。
- 每个总账单展示总收入、总支出、结余、账目笔数、统计起止日期。
- 分别展示收入分类和支出分类的金额与占比。
- “全部流水”按时间倒序排列，点击账目可直接进入原有编辑流程。
- 当前周期的未来日期账目也计入完整月账单或年账单；普通统计折线仍只统计到今天。

## 兼容性

包名继续为 `com.liujii.ledger`，最低支持 Android 8.0。数据库、业务 JSON 与完整备份格式不变，已有数据无需迁移。

正式包沿用原签名，可覆盖安装 1.1.18。安装前建议导出完整备份；不要卸载旧版。旧安装包、签名文件与保护备份继续保留。
